# Cyber Democracy Platform

## 📌 Overview

Cyber Democracy — це веб-платформа для аналізу, структурування та візуалізації законодавчих даних.  
Проєкт спрямований на підвищення прозорості державних рішень та спрощення доступу громадян до складних юридичних текстів.

Система дозволяє отримувати закони з відкритих джерел, парсити їх у структурований формат, переглядати через інтерактивний viewer та використовувати як основу для аналітики та AI-обробки.

---

## 🚀 Features

### 🏠 Landing Page
- Проблематика та рішення
- Блоки: Architecture, Users, Tech Stack, Roadmap
- CTA для переходу в viewer

### 📄 Law Viewer
- Інтерактивний перегляд законів
- Робота зі структурованими JSON-даними
- Підсвічування логічних блоків документа

### ⚙️ Parser System
- Парсинг законів з відкритих джерел (наприклад Верховна Рада)
- Перетворення тексту в структуровані блоки
- Підготовка даних для аналітики та AI

### 👥 Team Page
Проєкт включає ключові ролі:

- Product / Vision Lead — стратегія продукту
- Frontend Developer — UI, React інтерфейс
- Backend Developer — API, логіка, дані
- Data / AI Engineer — парсинг, NLP, структура законів
- DevOps Engineer — деплой, інфраструктура
- UI/UX Designer — дизайн і користувацький досвід
- Research / Policy Analyst — аналіз законодавства
- Security Engineer — безпека системи
- SMM / Community Manager — комунікація та розвиток спільноти

## 🧠 Architecture

SPA-архітектура:

- Frontend: React
- Routing: state-based (`page` switching)
- Data model: JSON laws structure
- Viewer engine: dynamic rendering
- Backend (planned): FastAPI / Python services
